# CIN Prototype — Submit an Event Update

This version adds a prototype event-submission flow while preserving the existing CIN visual language.

## New in this update
- Global prototype disclaimer
- Submit an Event link in hamburger navigation
- Submit an Event button on Home
- Full event-submission form
- Accessibility / accommodations field
- Simulated review acknowledgement
- Submission confirmation screen
- Submitted event is temporarily added to Events and Calendar
- Submitted event can be opened like any other event
- Additional disclaimer language in About and Help

## Important prototype behavior
Submitted events are stored only in the current browser session. Reloading the page restores the original fictional demo data.
